# راهنمای افزودن مسابقه (فقط ۳ قدم، بدون ترمینال)

1. در GitHub (مرورگر یا گوشی) فایل `inbox/race.txt` را باز کن و روی آیکن مداد (Edit) بزن.
2. بالای خط `---` شماره‌ی دور را بنویس و زیر آن، متن صفحه‌ی نتیجه‌ی F1.com را همان‌طور که هست پیست کن
   (اگر جدول رده‌بندی رانندگان را هم زیرش پیست کنی، امتیازها خودکار با آن چک می‌شوند).
3. «Commit changes» را بزن. بعد از چند دقیقه داده‌ها به‌روز می‌شوند و Vercel سایت را دوباره منتشر می‌کند.

نتیجه (موفق یا خطا) همیشه در `inbox/STATUS.md` نوشته می‌شود. اگر خطا بود هیچ داده‌ای تغییر نکرده؛
فقط `race.txt` را اصلاح و دوباره ذخیره کن.

## مثال

```
round: 21
official: 19
fastest: LEC 1:37.976 lap 42
--- 
(اینجا متن F1.com)
```

نمونه‌ی کامل و واقعی: `inbox/archive/round-20.txt` (آستین).

## خطوط اختیاری بالای `---`

| خط | معنی |
|---|---|
| `official: 19` | شماره‌ی رسمی دور (اگر با شماره‌ی پروژه فرق دارد) |
| `fastest: LEC 1:37.976 lap 42` | سریع‌ترین دور. سکتورها اختیاری: `s1=25.1 s2=38.0 s3=34.8` |
| `classified: BOT` | فقط در حالت نادر: راننده‌ای که F1.com او را NC نوشته ولی FIA رسماً کلاسه‌بندی‌اش کرده. معمولاً لازم نیست؛ NC را همان‌طور بگذار |
| `sprint: ANT RUS HAM ...` | ترتیب کدهای اسپرینت (فقط آخر هفته‌های اسپرینت) |
| `laps: 56` · `winnertime: 1:35:16.650` · `pole: 1:34.035` · `distance: 5.513` | اطلاعات تکمیلی |
| `note: متن کوتاه` | یادداشت مسابقه |

## چه چیزی چک می‌شود؟

- همه‌ی کدهای راننده باید در رده‌بندی پروژه باشند.
- ترتیب جایگاه‌ها باید ۱، ۲، ۳، ... بدون جای خالی باشد.
- اگر جدول رده‌بندی پیست شده باشد، مجموع امتیاز هر راننده باید با آن برابر باشد.
- بعد از افزودن، `audit-data.cjs` اجرا می‌شود. اگر خطا داشت، همه‌چیز به حالت قبل برمی‌گردد.
- یک دور را نمی‌شود دو بار اضافه کرد.

## راه‌اندازی یک‌باره

در GitHub: Settings ← Actions ← General ← Workflow permissions ← **Read and write permissions** ← Save.
